### 🧑‍💻 About Me

I am a Developer and AI Enthusiast based in India, building **offline-first systems**, **Generative AI** pipelines and **Workflow Automation**. I like problems where the network is unreliable, the stakes are real, and the easy answer doesn't survive contact with the field.

* 🔭 I’m currently building **SafeSphere** — a three-layer flood-victim detection system: two Flutter apps, an officer dashboard, passive stillness detection, and a BLE/Wi-Fi mesh relay that delivers an SOS with **zero internet**.
* 🌱 Learning more about **Model Quantization** and **On-device AI** with Ollama.
* 🧰 I self-host almost everything — Supabase, n8n, CI runners and my own dashboards on a Linux box behind a Cloudflare Tunnel.
* ⚡ Fun fact: I love building assistants that handle the "boring stuff" so I can focus on building cool stuff.
